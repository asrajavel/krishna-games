# Image Generation Style

When generating artwork for this project, use a polished 2D Indian storybook
illustration style that matches the existing Vrindavan road assets.

Use this prompt direction:

> Bright, cheerful 2D Indian storybook game artwork with painterly texture,
> vivid turquoise-blue skies, soft white clouds, warm sunlight, lush green
> countryside, distant blue-green hills, flowering grass, and richly detailed
> leafy trees. Use clean, readable silhouettes, saturated harmonious colors,
> gentle depth, and a welcoming Krishna festival pilgrimage mood. Compose for
> a large monitor with clear focal areas and uncluttered space for UI overlays.
> No photorealism, 3D rendering, harsh neon colors, borders, frames, labels,
> letters, or baked-in text unless explicitly requested.

Use existing related images as references whenever possible so new assets keep
the same palette, lighting, detail level, and perspective.
